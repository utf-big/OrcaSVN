# OrcaSVN v0.6.4.20261026

本仓库基于 [wustites/OrcaSVN](https://github.com/wustites/OrcaSVN) v0.6.4 二次开发，本次发布为 `dev` 分支的**预发布**构建，希望大家对上游项目多多支持。

## dev 分支相对上游 v0.6.4 的主要变动

- **检出**：改为流式执行并展示进度日志；失败时按阶梯重试（整包传输 → 逐文件传输 → 关闭压缩并延长超时），页面切换时日志即丢弃，不做本地留存。
- **跳过失败项继续检出**：服务器无法提供部分内容时，先取目录骨架再逐目录取全，保留已下载内容，只报告真正缺失的文件。
- **继续检出**：取消或中断后可在「更新」页继续，浅深度工作副本会被补到完整深度。
- **工作副本被锁**：检测到 `E155004` 时自动执行 `svn cleanup` 后重试；更新页、检出页、工作区均提供「清理」入口。
- **编码规范化**：统一处理 NFC/NFD 与 UTF-8 路径，避免中日文混合路径被误判为未入库/缺失；可一键修复文件名、删除仓库内的重复条目。
- **工作区**：新增切换仓库地址、合并、标记已解决、安排删除、修复文件名、删除重复条目；右上角工具栏「打开方式」旁新增「远程仓库」，用系统浏览器打开当前工作副本地址。
- **提交页**：支持变更明细的删除与还原。
- **工作区时机**：检出时，SVN 建好 `.svn` 后立即把目标目录设为当前工作区；中断后可继续。
- **macOS 快捷键**：`⌘W` 只关闭（隐藏）窗口，`⌘Q` 退出程序。
- **自动更新检查**：本构建已关闭，并在「设置 → 关于」注明二开来源与上游地址。

## Changes since upstream v0.6.4

- **Checkout** streams its progress, retries through a three-step ladder (bulk transfer, per-file transfer, no compression with a longer timeout), and keeps the log on screen only while the page is open.
- **Continue past failures**: fetch the directory skeleton first, then fill directory by directory, keeping what arrived and reporting only what the server could not deliver.
- **Resume** a cancelled checkout from the update page; working copies left at an immediate depth are completed to full depth.
- **Locked working copies** (`E155004`) are cleaned up automatically before a retry, and every relevant page offers a cleanup action.
- **Name normalisation** handles NFC/NFD and UTF-8 paths so mixed Japanese and Chinese paths stop being reported as missing; mis-normalised names can be repaired and repository duplicates deleted.
- **Workspace** gains switch, merge, resolve, schedule-delete, repair-name and delete-duplicate actions, plus a "remote repository" toolbar action that opens the working copy URL in the browser.
- **Commit page** can delete and restore individual change entries.
- **Workspace timing**: the target becomes the current workspace as soon as SVN creates `.svn`, and an interrupted checkout can be resumed.
- **macOS shortcuts**: `⌘W` closes (hides) the window, `⌘Q` quits the app.
- **Update checking** is switched off; the about section names the upstream project and links to it.

## Downloads / 下载

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| Windows | `*_x64-setup.exe`（NSIS）或 `*_x64_en-US.msi` | 未代码签名，首次运行可能触发 SmartScreen 提示 |
| macOS（Apple Silicon） | `*.dmg` | 未签名、未公证；首次打开请右键「打开」，或执行 `xattr -d com.apple.quarantine /Applications/OrcaSVN.app` |
| Linux | `.AppImage` / `.deb` | 需要本机可用的 `svn` 命令行 |

本应用是 SVN 命令行的图形前端，**所有平台都需要本机可用的 `svn` 命令**。

This app is a GUI over the SVN command line: an `svn` executable must be available on all platforms.

## 已知限制 / Known limitations

- 服务器端版本文件损坏（如 `E000005: Can't read file … Input/output error`）无法在客户端绕过；可先用「跳过失败项继续检出」拿到其余内容。
- macOS 构建未签名未公证，Gatekeeper 会拦截首次启动。
- Windows 构建未代码签名，SmartScreen 可能提示。
